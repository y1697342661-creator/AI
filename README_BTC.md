# BTC Perpetual Futures Specialist Quant System v1.0
# 比特币永续合约（OKX: BTC-USDT-SWAP）双周期量化交易系统

与 `mu_quant`（美光正股系统）**100% 物理隔离**的比特币永续合约量化研究、前瞻纸面交易与 OKX 模拟盘同步系统。

## 核心纪律与风控红线
1. **标的与模式**：OKX `BTC-USDT-SWAP` 永续合约，**严格逐仓（`isolated`）**，禁止全仓连环爆仓。
2. **受控低杠杆**：多头上限 `2.0x`、空头上限 `1.2x`、系统硬顶 `3.0x`，按 14 日下行波动率动态缩放仓位（波动放大时自动降杠杆）。
3. **无未来函数与真实合约成本**：
   - 所有 1D 宏观指标按“日线收盘完成时间（`day_open + 24h`）”向后对齐 4H K 线。
   - 严格 **4H 收盘出信号 → 下一根 4H 开盘成交**，计入双边 Taker 手续费 + 滑点（默认 8 bps/边，压力测试 15 bps/边）。
   - 计入真实 8 小时资金费率现金流（最近 90 天为 OKX 真实费率，更早历史采用保守 0.01%/8h 基准费率，绝不低估多头资金费损耗）。
   - 逐根 K 线按盘中极值（多头看 `low`、空头看 `high`）检验强平维持保证金（MMR=0.4%）与 ATR 移动止损。
4. **模拟盘硬隔离**：OKX 通道硬编码 `x-simulated-trading: 1` 且强制检查 `simulated_only: true`，**绝不触碰实盘资金**。
